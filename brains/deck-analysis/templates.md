# Deckanalyse Template

## Zweck

Dieses Brain dient zur Analyse vorhandener Commander/EDH Decklisten.

Die Analyse soll aus einer einfachen ManaBox-Deckliste ableiten:

- Commander
- Farben
- Spielplan
- zentrale Engines
- Payoffs
- Interaktion
- Win Conditions
- Schwächen
- Bracket-Einschätzung
- Gameplan

Die Analyse ist nur ein Vorschlag und wird erst gespeichert, wenn der Nutzer sie bestätigt.
